# Get Started

Vue-98 is a component library styled after Windows 98 Second Edition. Aiming for a pixel perfect and faithful recreation of the original OS components.

## Installation

```bash
npm i vue-98
```

## Styles

Add the stylesheet to your apps entry point.

```ts
import 'vue-98/dist/main.css'
```

## Usage Example

```vue
<script setup>
import { WButton } from "vue-98"
</setup>

<template>
    <WButton>Hello</WButton>
</template>
```

Refer to [Components](/components) for a full overview.
